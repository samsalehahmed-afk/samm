# مجلد الصور (images)

ضع هنا الصور التعليمية (رسومات كرتونية محترمة توضح الحركات)، بنفس الأسماء
المذكورة في حقل imageAsset داخل ملفات JSON، مثل:
- images/wudu/step1_niyyah.png
- images/prayer/03_takbir.png

في النسخة الحالية (MVP) تُستخدم رموز تعبيرية (emoji) كصور بديلة داخل الشاشات،
ليسهل استبدالها لاحقًا بصور حقيقية دون تعديل منطق الكود.
